Why upay Shield exists
Scam money survives today because by the time a victim reports it, the funds have already moved through several wallets and been cashed out. upay Shield scores every transaction the instant it happens, traces where flagged money is flowing using a transaction graph, and gives an analyst a plain-language reason for every alert — so suspicious transfers can be held before the money disappears, not investigated after.

Model & Architecture

Evaluated on a held-out test set never used for training — the rulebook's own responsible-AI requirement.

What the risk model weighs most
How a transaction gets scored
transaction → behavioral + network features (new recipient? unusual amount for this sender? new device? how old is the receiving wallet? how many strangers paid it in the last hour?) → risk model (gradient-boosted trees) → risk score → below 0.4 passes normally, 0.4–0.7 asks the customer to confirm, 0.7+ is held and sent to this dashboard with an AI-written case summary for an analyst to decide. The model is never allowed to block money on its own — see Section 14 of the hackathon's Responsible AI requirements.
